# Literary — Design & Build Brief

`index.html` is a self-contained, styled brief for **Literary**, an aesthetic,
minimalist reading-tracker and book-discovery app. Open it in a browser to read it.

It covers:

- **Design language** — palette (parchment, ink-green, brass), fonts (Fraunces / Newsreader / JetBrains Mono), and voice.
- **Five tabs** — Shelf, Discover, Trending, Word of the Day, Stats & Goals — with in-page mockups.
- **Settings** — where the one-time Goodreads CSV import ("The Bridge") lives.
- **Data model & stack** — a small schema plus a Replit-friendly stack.
- **A paste-ready Replit prompt** — copy it into Replit's AI agent to scaffold the app.

> Note: Goodreads retired its public API to new developers in 2020, so the import is
> designed around Goodreads' own "Export Library" CSV rather than a live API.
